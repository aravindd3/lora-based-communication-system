# Firmware source

This folder contains the ESP32/Arduino sketches supplied for the LoRa-based
communication system. Each sketch is in a directory with the same name so it
can be opened directly in the Arduino IDE.

| Folder | Contents |
| --- | --- |
| `microphone_oled_waveform` | I2S microphone input shown as a waveform on the OLED. |
| `microphone_ptt_waveform` | I2S microphone waveform display enabled by a push-to-talk button. |
| `oled_contact_menu` | OLED contact-selection and talk-screen interface. |
| `lora_ptt_control` | LoRa busy-channel and push-to-talk control signalling. |
